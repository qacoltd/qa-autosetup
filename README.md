# QA AUTOSETUP

Windows tool for technicians: sets up a PC for Ricoh scan-to-folder (SMB/FTP), adds Ricoh printers (A4, 1-sided, job type, user code) and installs/configures FileZilla Server.

## Download
Go to **Releases** and download `QA AUTOSETUP.zip`.

## Use
1. Extract the zip (Windows: Extract All; WinRAR: Extract to `QA AUTOSETUP\`) and open the folder.
2. Run `QA AUTOSETUP 3.1.exe` as administrator.
3. When finished run `QA CLEANUP.exe` in the same folder: it removes the program, the downloaded zip and its Recycle Bin copies.
